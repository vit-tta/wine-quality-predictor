#  Wine Quality Predictor

Приложение на Streamlit для оценки качества вина с помощью логистической регрессии. Позволяет оценивать одно вино, смотреть метрики модели на тестовой выборке, делать пакетные предсказания по CSV-файлу и изучать коэффициенты модели.

## Требования

- Для работы приложения требуется интерпретатор Python версии 3.15 (проверено на Python 3.15.2).

## Установка и запуск

### Шаг 1. Откройте терминал и перейдите в папку с приложением:

```cd путь/к/папке/wine_app```

### Шаг 2. Создайте виртуальное окружение :

```python3 -m venv .venv```

### Шаг 3. Активируйте виртуальное окружение:

На macOS и Linux:```source .venv/bin/activate```

На Windows:
```.venv\Scripts\activate```

После активации в начале строки терминала появится (.venv).

### Шаг 4. Установите все необходимые библиотеки из файла requirements.txt:

```pip install -r requirements.txt```

### Шаг 6. Запустите приложение:

```streamlit run app.py```
